ОМЕГАБУД — сайт будівельних послуг
=================================

Файли:
- index.html — структура сайту, тексти та форма заявки
- styles.css — адаптивний дизайн
- script.js — мобільне меню та підготовка заявки для пошти або SMS

Перегляд:
1. Розпакуйте архів.
2. Відкрийте index.html у браузері.

Важливо:
- Форма зараз не надсилає дані на сервер і не зберігає заявки. Вона готує текст для пошти omegabuild.khm@gmail.com або SMS на номер +380979623063. Надсилання завершує відвідувач у поштовому чи SMS-застосунку.
- Перед публікацією перевірте номер телефону, назву, перелік послуг і тексти.
- Для справжнього приймання заявок через сайт потрібно підключити серверну форму або зовнішній сервіс форм.
- Домен і хостинг не входять до архіву. Щоб сайт став доступний усім, його потрібно розмістити на хостингу.
