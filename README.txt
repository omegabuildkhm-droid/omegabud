Омегабуд — багатосторінковий сайт

Публікація: автоматично через підключений GitHub / Netlify.
Команда: npm run build. Каталог: dist. Налаштування: netlify.toml.

Керування: /admin/ — вхід наявним акаунтом власника Supabase.
Об’єкти та фото → Додати об’єкт → завантажити фото → Показувати на сайті → Зберегти.
Заявки приймаються на сервер і доступні в панелі. Поштові сповіщення поки не підключені.
Внутрішня аналітика збирається за згодою відвідувача. Для GA4 потрібно додати Measurement ID.
Покази та кліки в Google потребують окремого підключення Search Console.

Детальна документація й обмеження — README.md.
